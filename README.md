# blender-material-preview-sheet

A Blender add-on that generates organized material preview sheets with automated lighting, camera framing, and export options.

## Stack

Primary language: **Python**

## Project structure

- `__init__.py` — Automate creation of material preview grids from scene collections with export to .blend or PNG.
- `constants.py` — default values
- `utils.py` — grid and material helpers
- `lighting.py` — light and camera setup
- `export.py` — save and render functions
- `ui.py` — panel and properties
- `operators.py` — main operator logic
- `requirements.txt` — empty

## Usage

Review the source files and install any dependencies referenced by the project before running it.
